# Sahil-Enterprises Admin

The **Admin** panel allows authorized personnel to manage products, orders, and user accounts on the Sahil-Enterprises platform.

## Features

- Product CRUD (Create, Read, Update, Delete)
- View and manage orders
- User management
- Dashboard overview
- Future integration with backend API for full control

## Tech Stack

- React.js (Vite)
- React Router DOM
- Tailwind CSS
- Material UI (MUI)
- React Icons
- Context API
